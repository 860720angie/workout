# Pitch Ready

A 4-day gym plan for soccer: conditioning first, hip and glute strength, then core every day. The core block is the same four targets each session: upper abs, lower abs, obliques, and one hard exercise for the side of your ribs. Tuesday and Saturday mix shadow boxing, elbows, knees and easy kicks in with the running. Built-in rest and interval timers with a beep, so rest doesn't stretch the session. Installable, works offline. Edits are saved on your own device.
